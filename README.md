## SuperWriter

_The machine every kid dreams of_

It's basically a 'homework machine' like you imagine it. It takes samples of your handwriting, takes text input and writes in on a piece of paper in your handwriting.

Of course, the intent of this project is not to endorse academic dishonesty, but to learn about machine learning.

This project was made for hack club terra, which's theme this week was ***_Fantasy_***. I know it's supposed to be dragons and stuff, but this is like a _fantasy_ of a young boy doing homework wishing for a machine doing it for him...
